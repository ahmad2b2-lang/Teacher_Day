# Teacher Day Tribute · تكريم يوم المعلم

A small, mobile-friendly Arabic web app for World Teachers' Day (5 October).

1. **Welcome**: the Shawqi verse and the teacher's name (default: الخالة أم سيد يوسف).
2. **Your students grew up**: tap each schoolgirl to "teach" her and see who she became.
3. **Quiz**: four slider questions (years, students per class, classes per year, periods per week).
4. **Thank you**: years of service, students taught and total periods taught.
5. **Certificate of appreciation**: with the teacher's name and totals, and applause.
6. **Gift**: unwrap a gift card.

## Run it
Open `index.html` in a browser. It is a single file with no build step.

## Gift card
The gift card image is not in this repository because the repo is public and the card's code could be used by anyone.
To show it, add the image as `gift-card.jpg` next to `index.html` (only once the repo is private).
